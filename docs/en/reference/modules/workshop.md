# Workshop and publication

A subscription is not the installed runtime directory. The host validates/copies complete content into owned versions. Only reliable service results establish unsubscription; network failure alone never removes content. Removing the last account association disables affected instances and cleans owned data under the host rules. Layout subscriptions are not auto-applied and missing dependencies do not trigger auto-subscription. Development publication validates current matching-identity source into a clean upload copy, initially private, without replacing the running version. Steam availability and actual client acceptance need separate verification.
