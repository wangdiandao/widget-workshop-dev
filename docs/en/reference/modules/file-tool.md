# File-tool example

Statistics, HTTP input, finite previews, PNG processing, directory watching and clipboard output share explicit operation slots and cancellation. Temporary file/stream/export handles have owners and release paths. Invalidated configuration/grants clear derived results and reject late completion. Exports use staging plus trusted save/overwrite, while uncertain cancellation reports that already committed external effects may remain. Images need decoded-size bounds. Directory watch prompts bounded rescans rather than durable event replay.
