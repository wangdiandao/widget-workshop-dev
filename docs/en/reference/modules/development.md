# Development and author SDK

The host injects SDK before page scripts and reloads. Bind a runnable directory rather than a development server. Source changes stabilize for at least one second, then copy/validate into an immutable version. Invalid candidates and missing directories preserve the last usable installation. Unsaved configuration drafts postpone automatic activation; manual actions preserve save/discard/continue editing. Relocation keeps widgetId; removal preserves author source. Developer tools require an enabled ready display instance. Restoring the previous package disables automatic reload. See the lessons for race and cleanup patterns.
