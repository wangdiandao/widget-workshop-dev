# 信息流：单任务刷新与可信显示

examples/information-feed 可直接作为开发组件检查输入。默认展示包内模拟数据；配置 endpoint 后才请求远端。它使用 network.request、实例 KV 离线快照和可拒绝的 external.open，拒绝外链权限不影响阅读。

## 数据适配契约

```json
{
  "items": [
    {"id": "article-1", "title": "一条资讯", "url": "https://example.com/article"}
  ]
}
```

示例接收该 JSON，不直接解析 RSS。接 RSS/Atom 时另写有界适配器，再归一化为同一模型；不要把 XML/HTML 原文作为 innerHTML。示例最多检查 500 条输入，展示 50 条，标题不超过 200 字符、ID 128 字符，网址仅接受无凭据的 HTTPS。所有标题通过 textContent 呈现。

## 刷新状态机

读取上次成功快照后再刷新；一次只有一个请求，新配置取消旧请求，代次检查拦住迟到结果。十二秒为此示例超时，刷新间隔在 30–3600 秒之间；本次完成后再安排下一次。隐藏、锁屏、挂起和离页时取消非必要任务，恢复后重新读取当前配置。

远端非 2xx、非法 JSON、过大正文或模型不匹配均保留已有内容并显示失败。刷新成功但离线快照写入失败单独提示，不能把已经取得的新内容说成请求失败。不要无限重试；定时刷新就是下一次有界尝试。

## 账号、限额与安全

公开资讯不需要秘密；需要账号时由组件按服务官方流程登录，令牌放凭据或用户秘密绑定，不能写进 endpoint、分享配置、包或日志。网络不是 Capability。HTTP 代理和浏览器 fetch 的能力不同，不应靠远程脚本或任意代理绕过接口边界。

可扩展功能包括按 stable ID 去重、已读状态、手动来源切换和静态摘要。订阅地址、已读状态与完整内容各自限额；缓存不能被当作可靠永久存档。验证拒绝外链、恶意标题/URL、断网、超时、连续刷新、配置变化与离页后的迟到结果。
