# Contribution Policy

This repository does not accept external contributions or pull requests, including code, documentation, translations, examples and Skills.

You can [open an Issue](https://github.com/wangdiandao/widget-workshop-dev/issues/new/choose) to report a problem, suggest a feature or ask a question.

For a problem report, include the affected page or component, reproduction steps, expected and actual behavior, relevant versions and error codes. Do not include access tokens, credentials, private files or personal data.
